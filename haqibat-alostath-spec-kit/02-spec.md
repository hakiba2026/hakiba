# المواصفة الوظيفية الكاملة — حقيبة الأستاذ

## 1. نظرة عامة

منصة SaaS جزائرية (عربي/فرنسي) للأساتذة، تولّد دروسًا/تمارين/امتحانات بالذكاء الاصطناعي، عبر اشتراك مدفوع (شهري/نصف سنوي/سنوي). الدفع الفعلي الوحيد هو تكلفة استدعاءات الذكاء الاصطناعي؛ باقي البنية التحتية على Cloudflare Free Tier (راجع `03-plan.md`).

## 2. الأدوار (Roles)

| الدور | الوصف |
| --- | --- |
| Super Admin | كل الصلاحيات + إدارة المدراء الآخرين |
| Content Admin | إدارة الشعب/المواد/الوحدات، مراجعة المحتوى المولَّد |
| Support | عرض حسابات المستخدمين، تمديد اشتراك، بدون حذف أو إعدادات مالية |
| Billing | عرض الإيرادات، الاشتراكات، الأكواد — بدون إدارة المستخدمين |
| Teacher | المستخدم النهائي المشترك، يستعمل لوحة تحكم الأستاذ |

## 3. البنية البرمجية (تفصيل كامل في `03-plan.md`)

نظام Modules/Plugins: كل ميزة = مجلد مستقل تحت `/modules/<اسم>` بصيغة (`manifest.ts`, `ui/`, `api/`, `schema.sql`, `lib/`)، عزل صارم، والتواصل بين الميزات فقط عبر `/core` (`auth`, `plugin-registry`, `i18n`, `db`, `storage`, `ui-kit`, `queue`).

## 4. لوحة تحكم المدير العام (Super Admin)

تُنشر كمشروع Cloudflare Pages **منفصل تمامًا** على نطاق فرعي مستقل (مثل `admin.<domain>`)، محمي بـ Cloudflare Access (راجع `06-security.md`).

### 4.1 إدارة المستخدمين
إضافة / تعديل / تعطيل مؤقت / أرشفة (لا حذف نهائي افتراضيًا) لأي حساب أستاذ.

### 4.2 إدارة الباقات (Plans)
حقول: الاسم، السعر، المدة (شهر / 6 أشهر / سنة)، حصة التوليد الشهرية (عدد دروس/تمارين/امتحانات)، قائمة الـ plugins المتاحة افتراضيًا لهذه الباقة (عبر `plan_plugins`).

### 4.3 إدارة الاشتراكات
إسناد اشتراك يدويًا لمستخدم، تمديد، إلغاء، تجميد.

### 4.4 أكواد تفعيل الاشتراك (تدفق كامل)
1. عند تأكيد الدفع (يدويًا من المدير، أو تلقائيًا عبر webhook من بوابة دفع إن وُجدت)، يُنشئ النظام سطرًا في `activation_codes`: `code` (فريد، صيغة مقترحة `HQB-XXXX-XXXX-XXXX` مع رمز تحقق checksum لمنع التخمين)، `plan_id`، `duration_days`، `status` (`unused`/`used`/`expired`)، `linked_email`، `expires_at`.
2. يُرسَل الكود بالبريد الإلكتروني لمن دفع، عبر مزوّد خارجي (Resend/Brevo/Postmark) — **ليس** عبر Cloudflare Email Routing (مخصص للبريد الوارد فقط).
3. الأستاذ يُدخل الكود في حسابه → تفعيل تلقائي للاشتراك + تعليم الكود `used` (استخدام واحد فقط، غير قابل لإعادة الاستخدام، ويُرفض إن كان منتهي الصلاحية).

### 4.5 إعدادات الموقع
اللغة الافتراضية عربي/فرنسي (تبديل تلقائي RTL/LTR في كل الواجهة)، الشعار، معلومات التواصل، الشروط والأحكام، وضع الصيانة (Maintenance Mode).

### 4.6 التصنيف الأكاديمي (Taxonomy)
هرمي: المرحلة الدراسية ← الشعبة/التخصص ← المستوى/السنة ← المادة ← الوحدة التعليمية. تُدار بالكامل من لوحة المدير، وتُستخدم في معالج توليد الدرس (القسم 6).

### 4.7 ميزات إضافية إلزامية
سجل تدقيق (Audit Log) غير قابل للتعديل لكل عملية حساسة، لوحة تحليلات إيرادات/استخدام/churn، أكواد خصم (Coupons)، نظام إحالة/عمولة، طابور مراجعة عشوائية للمحتوى المولَّد، إدارة مفاتيح API لمزوّدي AI (تدوير + حدود استهلاك)، تصدير/نسخ احتياطي دوري (CSV)، إشعارات تلقائية (قرب انتهاء الاشتراك، قرب استهلاك الحصة الشهرية)، توثيق هوية الأستاذ، محرر ترجمات i18n، ضبط Rate Limits لكل باقة من اللوحة مباشرة.

### 4.8 RBAC
أدوار منفصلة قابلة للتركيب (Super Admin / Content Admin / Support / Billing) بدل حقل `isAdmin` بسيط — راجع `06-security.md`.

## 5. نظام الصلاحيات/Plugins في لوحة تحكم الأستاذ

جداول:
- `plugins` (id, key, name_ar, name_fr, icon, category)
- `plan_plugins` (plan_id, plugin_id)
- `user_plugin_overrides` (user_id, plugin_id, enabled)

طريقة العمل: عند تسجيل الدخول، "الصلاحية الفعلية" = (إضافات باقة المستخدم) + (استثناءات تفعيل يدوي) − (استثناءات تعطيل يدوي). تُحسب وتُخزَّن في KV لتسريع العرض. الواجهة (Sidebar) تعرض فقط الـ plugins المفعّلة. **الأهم**: middleware كل مسار API يتحقق من الصلاحية الفعلية في الخادم أيضًا، بصرف النظر عن الواجهة.

شاشتا إدارة في لوحة المدير: "صلاحيات الباقات" (الباقات × الإضافات) و"صلاحيات فردية" (الأساتذة × الإضافات).

## 6. معالج "إضافة درس جديد" (خطوة بخطوة)

1. المرحلة الدراسية (ابتدائي/متوسط/ثانوي)
2. الشعبة/التخصص (عند الحاجة)
3. المادة
4. المستوى/السنة الدراسية
5. الوحدة التعليمية/الفصل (من تصنيف القسم 4.6)
6. نوع المحتوى: درس كامل / تمارين / اختبار (مع سلّم تنقيط وحلول)
7. الكفاءة المستهدفة والأهداف التعليمية — مقترحة تلقائيًا بالذكاء الاصطناعي (مقاربة APC)، قابلة للتعديل
8. خيارات إضافية: اللغة، مدة الحصة، مستوى الصعوبة، عدد الأسئلة
9. إطلاق التوليد عبر نظام الطابور (لا يحجب الواجهة) — راجع `03-plan.md`
10. معاينة وتعديل يدوي
11. حفظ في مكتبة الأستاذ الخاصة + تصدير PDF/Word

## 7. واجهة المستخدم

Mobile First كامل، Header وSidebar ثابتان و responsive، اتجاه منطقي (logical CSS) لدعم AR/FR تلقائيًا، دعم PWA. التفصيل الكامل (breakpoints، مكوّنات UI Kit، سلوك النماذج) في `05-design-system.md`.

## 8. الأمان

تفصيل كامل إلزامي في `06-security.md` (عزل لوحة المدير، Zero Trust، 2FA، RBAC، Audit Log، JWT قصير الأمد، Turnstile، Rate Limiting، تحقق خادم صارم، حماية من الحقن وXSS).

## 9. النموذج التجاري

اشتراكات (شهر / 6 أشهر / سنة)، حصة توليد شهرية لكل باقة، الدفع الوحيد الفعلي على المشروع هو تكلفة استدعاءات AI (+ بريد صادر عند تجاوز الحصة المجانية).
